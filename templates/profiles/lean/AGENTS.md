# Perfil Lean

Perfil leve para manutenção rápida, scripts, bibliotecas e tarefas pequenas.

## Ferramentas principais
- Serena para navegação semântica.
- CodeGraph para estrutura e impacto.
- Context7 para documentação técnica pública atual.
- RTK global.

## Regras
- Priorize baixo consumo de contexto e alterações pequenas.
- Não faça varreduras amplas sem necessidade.
- OpenSpec é opcional: use apenas quando o projeto já o adotar ou quando solicitado.
- Evite introduzir processos e ferramentas adicionais sem necessidade.
- Não faça refatorações oportunistas.
