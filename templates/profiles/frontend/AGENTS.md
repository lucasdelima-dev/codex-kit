# Perfil Frontend

Perfil focado em UI, UX, acessibilidade, comportamento visual e aplicações web.

## Ferramentas principais
- Serena, CodeGraph e Context7.
- Beads e Repomix.
- UI/UX Pro Max para direção visual e design system.
- Web Design Guidelines para auditoria.
- agent-browser para inspeção rápida.
- Playwright CLI para E2E e regressão.
- Chrome DevTools CLI para diagnóstico.
- OpenDesign para exploração e prototipação.
- DBHub somente quando configurado pelo projeto.
- RTK e OpenSpec disponíveis.

## Regras
- Quando houver OpenSpec, preserve seu escopo e decisões.
- Não redesenhe interfaces além do solicitado.
- Verifique visualmente mudanças relevantes.
- Use browser automation proporcionalmente à tarefa.
- DBHub é por projeto e readonly por padrão.
