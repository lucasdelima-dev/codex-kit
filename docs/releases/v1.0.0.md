# Codex Kit v1.0.0 — Notas de lançamento

## Visão geral

A v1.0.0 representa a primeira versão estável do
Codex Kit: um ambiente portátil de desenvolvimento
assistido pelo OpenAI Codex, com ferramentas integradas,
versões fixadas e configuração orientada a máquina,
perfil e projeto.

O Codex Kit é um projeto independente e não é afiliado,
patrocinado ou mantido pela OpenAI.

## Funcionalidades principais

- Bootstrap automatizado para Linux, macOS e Windows.
- Manifesto centralizado de versões e dependências.
- Oito perfis Codex com configurações independentes.
- Perfil `full` como padrão e `intraer` mais restritivo.
- Separação entre configurações globais e por projeto.
- Integração de OpenSpec, Serena, CodeGraph, Beads,
  DBHub, Semgrep, Repomix e Playwright.
- Wrappers e diagnóstico com `codex-doctor`.
- Instalação e reconciliação projetadas para serem
  idempotentes.

## Instalação

### Linux e macOS

```bash
git clone https://github.com/lucasdelima-dev/codex-kit.git ~/.codex-kit
~/.codex-kit/bin/bootstrap-machine
~/.codex-kit/bin/bootstrap-profile all
```

### Windows — PowerShell

```powershell
git clone https://github.com/lucasdelima-dev/codex-kit.git "$HOME\.codex-kit"
& "$HOME\.codex-kit\bin\bootstrap-machine.ps1"
& "$HOME\.codex-kit\bin\bootstrap-profile.ps1" all
```

Após preparar a máquina, autentique o Codex
separadamente e configure os projetos necessários.

Consulte o README para o fluxo completo, incluindo
bootstrap de projeto e utilização dos perfis.

## Segurança e limitações conhecidas

A auditoria npm final, baseada em 12 pacotes
selecionados do manifesto, apresentou:

| Severidade | Pacotes sinalizados |
|---|---:|
| Crítica | 0 |
| Alta | 6 |
| Moderada | 4 |
| **Total** | **10** |

Duas vulnerabilidades conhecidas permanecem abertas:

- `GHSA-vfj7-8cjw-p6xm`: negação de serviço
  relacionada à dependência `braces`.
- `GHSA-hp3w-g68c-fv3c`: negação de serviço
  relacionada à dependência `sprintf-js`.

A atualização para CodeGraph 3.0.0 reduziu o número
de pacotes sinalizados de 12 para 10, mas não
eliminou esses avisos.

As medidas preventivas e avaliações de exposição
estão documentadas no
[Registro de Riscos de Dependências](../security/dependency-risk-register.md).

A auditoria npm não representa uma verificação
exaustiva de todos os componentes, cenários
ou dependências do Codex Kit.

O DBHub deve permanecer configurado somente por
projeto, com credenciais de privilégios mínimos.
O modo somente leitura não substitui as permissões
efetivas do banco de dados.
